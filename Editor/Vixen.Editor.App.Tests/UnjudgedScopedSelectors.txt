# ⚠ NOT DERIVED and not regenerable, for `UnprovedCombinatorPairs.txt`'s reason: the third column is

# somebody who chased the selector and can say what builds it. Every reason carries a `file:line`, and
# the test refuses one that does not.
#
# ⚠ The list can only SHRINK. A row a sweep starts crediting fails the test exactly as a new
# uncredited selector does.
#
# The kinds, because "unjudged" hid three different answers:
#   unreached  Something in this tree builds it, for content or a state no sweep puts it in — an
#              empty document, a ledger nobody attached, a running task. Live; the ladder is short.
#   api        A control-sheet rule for a composition the public API offers and nothing in this tree
#              calls. Not dead: `ControlTheme`/`AdvancedTheme` style what an application builds.
#   none       ⚠ An editor-sheet rule nothing in this tree CAN build — no path, not merely no state.
#              `UnprovedCombinatorPairs.txt` refuses such a row and sends its reader to delete the
#              rule; here each sits in a selector list styling a family of controls, so whether a
#              future drawer or plugin earns the entry is a decision rather than a correction, and it
#              is recorded rather than taken. A `none` row is a finding.
