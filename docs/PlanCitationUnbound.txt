# How many citations in each document bind to nothing and are pinned to nothing (#1388).
#
# `Vixen.DocGen.Tests.RealPlanCitationTests` checks every backticked `File.ext:NNN` in docs/**/*.md
# and every README.md. A citation bound to a symbol — `Symbol` (`File.cs:NNN`), or
# `File.cs:NNN` — `code` — fails the day the symbol leaves the line, and a pinned one —
# `File.cs:NNN@1a2b3c4d5` — is checked against the commit it describes. An unbound one fails only
# when its number lands on a blank line or a lone brace, so it can drift a hundred lines and still
# read as evidence; that is how ~140 plan citations came to point at the wrong code under a green
# sweep.
#
# ⚠ So a count here never moves silently. The check is equality, not a ceiling: a document that
# gains an unbound citation fails until the new one binds, pins, or the count here is raised in the
# same diff, where a reviewer sees it and can refuse it; a document that loses one fails until the
# count is lowered, so a fall is recorded and cannot be spent later. Re-pointing an unbound citation by reading it
# leaves its count alone, which is the point of counting rather than listing.
#
# One line per document: the count, whitespace, the document's path from the repository root.
# Citations listed in docs/PlanCitationExempt.txt are not counted here.
