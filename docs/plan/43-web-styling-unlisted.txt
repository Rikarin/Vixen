# Static tailwindcss utilities that docs/plan/43-web-styling-parity.tsv does not name.
#
# The ledger's `classes` column is Tailwind's static set for a root as the original survey
# transcribed it by hand, and for a good many roots it is short of what v4 actually ships. Until
# Tools/Vixen.TailwindParity existed there was no way to say how short, because the registry is not
# in this tree. It was 163 of v4's 890 static utilities named by no row; it is 150, because the
# `display` row's thirteen missing keywords went back where they belong.
#
# It is an exemption list in CheckWhitespace's shape, so it can only shrink. A static utility that is
# in neither the ledger nor this file fails as TWP005; a line here that a row has since listed fails
# as TWP006; a line here that v4 does not register at all fails as TWP007. Nothing adds to this file
# automatically.
#
# A line here is not a gap in the engine. It is a gap in the survey's record of Tailwind — and it
# matters because ParityLedger.Derive demotes a row to `partial` on a listed class that does not
# resolve and never promotes one for a class nobody listed. So every name below is a question the
# ledger has not asked Vixen, and some of them will demote a row that reads `works` today.
#
# Negative spellings (`-inset-full`) are left out entirely rather than listed: they are generated
# from the positive root and are a row's business only through it.
