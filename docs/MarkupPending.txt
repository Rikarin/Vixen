# View-shaped editor types still built in C# rather than in a `.vxml` beside them (#89).
#
# ⚠ This is the ratio issue #89 says is owed, written down so it is gated rather than re-measured
# by hand at every audit. `Vixen.Editor.Ui.Tests.MarkupRatioTests` fails when
#
#   * a class named *View, *Panel, *Inspector or *Popup under Editor/ has no `.vxml` sibling and is
#     not listed here — a new hand-built view has to say why it is one,
#   * a line here names a file that now has a `.vxml` beside it, or no longer exists: delete the
#     line in the same commit. So this list can only shrink.
#
# One line per file: its path from the repository root, whitespace, and the reason, which starts
# with one of four words. The difference between them is the whole point of the file:
#
#   canvas       one element with pan, zoom, hit-testing and painting inside it. There is no element
#                tree for markup to describe, and hit-testing happens in render pixels rather than
#                layout units, which markup does not express. Porting it would be a rewrite that
#                made things worse, and a count that included it would report progress by doing so.
#   machinery    builds rows from a descriptor at run time and is what `<PropertyField>` and the
#                markup inspector are implemented in terms of, so writing it in markup is circular.
#   not-a-view   a plain class or record that is named like a view and builds no element.
#   pending      a genuine candidate. Each still needs the model decision the issue names — a
#                snapshot model takes a `Signal<T>`, a live model gets signal-backed additively, and
#                bumping a revision counter to force redraws is the thing to avoid — and, because a
#                port is a visual change, an A/B of the same panel before and after.
#
# Measured 2026-09-22: 37 view-shaped types have a `.vxml`, 26 do not, and 10 of those 26 are
# candidates. The audit on the issue counted 34/23 on 2026-09-04 and listed InputDebugPanel and
# AgentDebuggerPanel among the unported; ⚠ both are partials of AssetEditorsModule that REGISTER a
# view, and InputDebugView.vxml and AgentDebuggerView.vxml exist — a name-shaped count that does not
# read the class declaration reports two ports that are already done.
