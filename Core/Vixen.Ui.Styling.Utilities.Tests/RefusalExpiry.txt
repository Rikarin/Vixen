# The expiry conditions this repository's refusals declare.
#
#     <ledger root, or the file the prose is in>  <kind>  <what it waits on>
#
# ⚠ DERIVED. Do not hand-edit: the clauses live in the `note` column of
# `docs/plan/43-web-styling-parity.tsv`, next to the prose they formalise, and — since #674 — in any
# `README.md` or doc comment in the tree, where a refusal is the same object with no column to sit
# in. This file is the committed census of both. Add or change a clause and re-run
# `RefusalExpiryTests` with VIXEN_REGENERATE=1 to write this back, then read the diff.
#
# ⚠ A prose clause is held to its condition and NOT to a row's state, because it has no row. The
# three files that define the clause grammar are not swept — a file teaching the syntax writes
# specimens, including a deliberately malformed one — and `.claude` is not descended into, because it
# holds a whole checkout per agent worktree and their copies of these files are not this tree's.
#
# Why the census exists at all, given that the clauses are already in the ledger: it is the answer
# to "what does this print on the day it does not run". A sweep that derives a set and checks each
# member of it reports nothing when the set is empty — a ledger whose notes lost their clauses, to a
# rewritten column or a forgotten convention, would go green. Holding the derived set against a
# committed one fails in both directions, so a clause cannot appear without review and cannot
# vanish without a red test. A count with a floor under it would not do: "at least one" and "more
# than one distinct reason" are the two guards this suite's neighbours have already had eaten by
# success.
#
# The three kinds, and they are not equally strong:
#
#   expires-with <root>   The refusal stands only while that ledger root is itself refused
#                         (`absent` or `inert`). The cited root's state is a computed column, so
#                         this needs no foresight and cannot be spelt around. Prefer it.
#
#   expires-on <Type>.<M> The refusal stands only while that member does not exist. A tripwire: it
#                         is walked around by anyone who names the arriving thing differently. The
#                         type must resolve, which is what keeps a misspelt anchor from being green
#                         for ever — a member that is absent because the type is absent is the
#                         failure mode this file would otherwise have. ⚠ A row carrying it may be
#                         `partial`, since 2026-09-05 and because of `hyphens`: a refusal that lives
#                         inside ONE KEYWORD of a root whose other keywords shipped is the most
#                         exposed kind there is, because the row's state column stops moving and
#                         nobody re-reads it. `hyphens: auto`'s second blocker closed in #600 and the
#                         sentence naming it stood in three files, unreachable by this suite.
#
#   expires-when-read <p> The refusal stands only while nothing in the engine reads that CSS
#                         property. As exact as `expires-with`, because its condition is the same
#                         measurement `InertProperties.txt` expires on — `UtilityConsumptionProbe`
#                         runs the frame. ⚠ It is the half that carries an allow-list line's verdict
#                         ONE DEPENDENCY EDGE OUT, to the ledger note that cites it in words; the
#                         anchor must be a property some family emits, or the condition could never
#                         come due. A row carrying it may be `partial` — that is what a half-read
#                         longhand is.
#
# ⚠ Rows share an anchor, which is the pattern worth looking for: a refusal that is one of several
# resting on one premise is the refusal most likely to be read as settled — and when that premise
# closes, they all rot at once and the suite reports only the first. Four did, on 2026-09-04:
# `perspective-*`, `rotate-x-*`, `scale-z-*` and `translate-z-*` all named
# `UiTransform.M33`, and #547 landed it. Three of them are `expires-with perspective-*` now, which
# is the stronger kind and collapses four tripwires to one. ⚠ This paragraph itself named the wrong
# three — it listed `rotate-z-*`, which has measured `works` for as long as the census has existed
# and never carried a clause at all. Prose beside a derived list is not derived.
#
# ⚠ AND THREE ROWS SHARE `UiVertex.W` ON PURPOSE NOW, which is the same pattern used deliberately
# rather than fallen into. `scale-*` and `translate-*` are `partial` on one class each — `scale-3d`
# and `translate-z-px` — and both of those close with the projective vertex, exactly as the four
# `absent` transform rows do. Until 2026-09-06 neither said so in a clause: `scale-z-*` and
# `translate-z-*` would have gone red on the day the vertex landed while the two `partial` rows
# beside them, whose state column stopped moving when their other keywords shipped, sat green with
# the class still unregistered. That is `hyphens`' shape, one root over. They anchor on the vertex
# directly rather than `expires-with perspective-*`, because `expires-with` demands the carrier be
# refused OUTRIGHT and these two half work. `Rikarin/Vixen#268`.
#
# ⚠ AND THREE MORE SHARE `LayoutStyle.WritingMode`, which is the first anchor here that is not a
# refusal's blocker but a working implementation's PREMISE. `float: inline-start` and
# `clear: inline-start` resolve against `direction` alone, and that is the whole of the resolution
# only while the inline axis is horizontal in every configuration this engine can be in.
# `Rikarin/Vixen#952` asks for exactly the field that ends that, and the day it lands
# `LayoutTree.ResolveFloatSide` is WRONG rather than incomplete — in `vertical-lr` `inline-start` is
# the top, which no arm of that switch can return. ⚠ Four files carried the sentence and every one
# of them attributed it to a decision `#282` did not take: #282 decided its own fourteen logical
# utility roots needed no writing mode, and named the one corpus fixture that does in the same
# breath. A premise repeated in four places under a closed issue's number is the most settled-looking
# thing in this repository and was joined to nothing.
