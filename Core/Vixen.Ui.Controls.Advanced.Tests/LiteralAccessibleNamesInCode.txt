# Every English word production C# hands a control to SAY: a string literal assigned to a watched
# property (`Label`, `Title`, `Message`, `Description`, `Name`, `AccessibleName`,
# `AccessibleDescription`) whose receiver is a control the probe heard speak that property.
#
#     <path><TAB><ReceiverType>.<Property><TAB><value>
#
# Held against the C# by
# `CodeAccessibleNameTests.Every_literal_spoken_name_in_code_is_in_the_committed_census`, EXACTLY
# and in both directions. Derived: re-run that test with VIXEN_REGENERATE=1 to write this back, and
# read the diff. `LiteralAccessibleNames.txt` beside it is the markup half (`Rikarin/Vixen#1338`).
#
# ⚠ A row is a word no translator can reach. The localisation gate compares an announced word
# against the DECLARATION table, and a word no class declares is not in it — so nothing but this
# file sees one.
#
# ⚠ The receiver decides, not the property name. `Message = "…"` is every `[LoggerMessage]` in the
# tree and `Title = "…"` every sample's window; neither is a row, because neither receiver is a
# control that speaks it. A receiver the syntax does not type, or a control this assembly cannot
# load — every control the editor declares for itself — is UNJUDGED rather than clean, and
# `The_code_scan_actually_ran` says how many.
#
# ⚠ This file can only shrink. A row leaving means a word moved into a `*Strings` class; a row
# ARRIVING is a new untranslatable name and is the loud direction.
