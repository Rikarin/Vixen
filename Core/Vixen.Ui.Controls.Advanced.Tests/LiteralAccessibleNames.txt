# Every English word a `.vxml` hands a control to SAY rather than to show: a `Label`, `Title`,
# `Message`, `Description`, `Name`, `AccessibleName` or `AccessibleDescription` attribute written as
# a literal rather than as an `@` expression reading a `*Strings` declaration.
#
#     <path><TAB><attribute><TAB><value>
#
# Held against the markup by
# `MarkupAccessibleNameTests.Every_literal_spoken_name_in_markup_is_in_the_committed_census`,
# EXACTLY and in both directions. Derived: re-run that test with VIXEN_REGENERATE=1 to write this
# back, and read the diff.
#
# ⚠ A row is a word no translator can reach. The control answers `NativeAccessibleName` with this
# attribute — `ButtonBase` with `Label`, `Alert` and `Dialog` with `Title`, `Toast` with `Message`,
# `Image` with `Description`, `Avatar` with `Name` — so the literal is what a screen reader says, in
# English, in every language. Nothing else in this repository can see one: the localisation gate
# compares an announced word against the DECLARATION table, and a word no class declares is not in
# it (`Rikarin/Vixen#1338`).
#
# ⚠ This file can only shrink. A row leaving means a panel's words moved into a `*Strings` class,
# which is the change it exists to make visible; a row ARRIVING is a new untranslatable name and is
# the loud direction.
#
# ⚠ The scan is over-inclusive on `Name`, which is a generic attribute only `Avatar` turns into a
# spoken name. A row on something else costs a line; a spoken name the scan declined to see costs a
# screen-reader user a word.
#
# ⚠ It is NOT over-inclusive about which lines it reads. A `<!-- … -->` comment quoting an attribute
# as an example, and a `Label = "Add"` in a `@code` body, are prose and C# about markup rather than
# markup; `VxmlLines` takes both out before the pattern runs, the same reader the tag census uses.
# Without that a reworded comment would move a committed row, in a file that is supposed to shrink.
